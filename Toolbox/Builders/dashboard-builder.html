Dashboard builder

Pick the tiles, charts and tables you want. The page writes a PowerShell script that reads the data from Microsoft Graph with your account, counts it and saves one HTML dashboard with charts (Chart.js). The page itself signs in nowhere and sends nothing: everything stays in your browser. The preview below uses made-up sample devices.
