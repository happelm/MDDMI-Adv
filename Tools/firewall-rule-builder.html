Firewall rule builder

Draft: This tool is new and has not been tested in class yet.

Pick the rule groups and add your own rules. The page builds the rule file for New-IntuneFirewallRulePolicy.ps1, which creates an endpoint security Windows Firewall Rules policy in Intune via Microsoft Graph. The page signs in nowhere and sends nothing: everything stays in your browser.

1. Policy

%MANAGEMENT% is a placeholder in the remote address of every catalog rule (and of custom rules that keep it). It stands for the hosts that may manage the device. Accepted values (Firewall CSP RemoteAddressRanges): an IPv4 or IPv6 address (10.10.0.5), a subnet (10.10.0.0/24 or 10.10.0.0/255.255.255.0), a range without spaces (10.10.0.5-10.10.0.20), or one of the keywords LocalSubnet, Intranet, RmtIntranet, Internet, DNS, DHCP, WINS, DefaultGateway, Ply2Renders. * means any address and must be the only value. LocalSubnet is the subnet of the device itself, so every client next to it may connect. Prefer the subnet or the addresses of your admin hosts (jump hosts, management servers).

2. Rule groups

Every group except Ping lets an account with local admin rights on the device run code remotely (SMB with admin shares and the service control pipe, WMI, WinRM, remote services and tasks). Opened to all clients, these rules allow lateral movement from client to client. Scope them with the management address.
